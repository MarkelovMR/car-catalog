# Каталог автомобилей

Консольная программа на Java 17. Хранит модель, мощность и год выпуска автомобиля. Реализованы базовый уровень задания и уровень 2 со своим двусвязным списком.

## Запуск

Нужен JDK 17 или новее. В папке проекта выполните:

```sh
sh run.sh
```

В Windows можно запустить `run.bat` из командной строки. Через IntelliJ IDEA: открыть папку проекта, выбрать JDK 17+, пометить `src/main/java` как Sources Root и запустить `cars.Main`.

Пример работы: выбрать пункт 2, указать `data/cars.csv`, затем выбрать пункт 3 и ввести порог мощности `120`. Программа выведет подходящие автомобили по возрастанию года выпуска. При одинаковом годе записи упорядочиваются по модели и мощности.

В меню также доступны добавление с клавиатуры, вывод всех автомобилей, получение и удаление записи. Нумерация записей начинается с 1. Пункт 0 завершает программу. При закрытии программы данные из памяти теряются, сохранения в файл нет.

## Файлы с данными

Формат CSV или TXT, кодировка UTF-8. Первая строка обязательна:

```text
model;power;year
Lada Vesta;106;2021
Toyota Corolla;122;2019
```

Поля разделяются точкой с запятой. Кавычки и многострочные поля не поддерживаются. Пустые строки пропускаются, BOM в начале файла допустим.

Для модели допускается от 1 до 80 символов, без `;` и управляющих символов. Мощность — целое число от 1 до 2000 л.с. Год — от 1886 до следующего календарного года включительно. Совпадающие записи разрешены: в каталоге может быть несколько одинаковых автомобилей.

Ошибочные строки пропускаются с пояснением и номером строки. Исправные записи загружаются. Если файл недоступен или заголовок неверен, текущий каталог сохраняется. Для примера ошибок есть `data/cars-with-errors.csv`.

## Как устроен проект

- `Car` — три поля автомобиля и проверка значений.
- `ChainList<E>` — своя коллекция с узлами и ссылками на соседей.
- `Garage` — хранение автомобилей и подготовка отчёта.
- `CarImporter` — чтение файла через `try-with-resources`.
- `CarConsole` — меню, ввод и сообщения об ошибках.
- `Main` — запуск программы.

Поле каталога объявлено как `List<Car>`, но в него помещается `ChainList<Car>`. Стандартные `ArrayList` и `LinkedList` для хранения автомобилей не используются. Наследование от `AbstractList` даёт совместимость с интерфейсом `List`; узлы, вставка, поиск по индексу и удаление реализованы в `ChainList`.

При добавлении узел связывается с левым и правым соседями. При удалении соседи связываются друг с другом. Первый и последний узлы хранятся отдельно, поэтому добавление в конец занимает O(1). Поиск по индексу занимает O(n). Итератор обходит узлы напрямую. Изменение размера списка во время обхода обнаруживается через `modCount`.

В `Garage.report()` данные проходят через `filter`, `sorted` и `map`. Фильтр отбирает машины по мощности, сортировка упорядочивает их по году, а `map` преобразует объекты в строки для вывода. Исходный порядок каталога сохраняется.

Уровень 2 можно проверить через пункты меню 1, 4, 5 и 6: добавление, вывод коллекции, получение элемента и удаление. Отдельной собственной сортировки здесь нет — она относится к уровню 3.

## Проверка

```sh
sh test.sh
```

Проверяются операции связного списка, границы индексов, итератор, валидация, отчёт, загрузка файлов и сценарии меню. Поведение коллекции сравнивается с эталонным списком на 1500 случайных операций с фиксированным seed. Внешние библиотеки не нужны.
